# 多武器协同打击目标毁伤仿真系统
基于蒙特卡洛算法模拟火力打击防护单位的毁伤效果
## 项目简介
本项目是基于**C语言**开发的多武器协同打击目标毁伤仿真程序，通过蒙特卡洛模拟方法，实现地面火炮、地地导弹、航空火力、武装直升机四种武器的**单方式/多方式协同打击**仿真，可计算目标毁伤数量、相对毁伤率、防护工程保存率等核心指标，适用于军事作战模拟、火力打击效能评估等场景。

程序采用模块化设计，包含目标输入、武器参数输入、打击仿真、数据统计、结果输出五大核心模块，支持自定义目标坐标、武器参数、模拟精度，满足多样化的火力打击仿真需求。

---

## 核心功能
1. **目标管理**：自定义目标数量、坐标，自动计算集群目标瞄准点
2. **武器仿真**：支持四种武器独立打击仿真，内置专业弹道/误差模型
3. **协同打击**：支持双方式、三方式、四武器协同打击仿真
4. **参数自定义**：可配置弹药数量、误差参数、毁伤半径、模拟精度等
5. **智能统计**：蒙特卡洛循环模拟，自动计算毁伤指标与置信区间
6. **结果输出**：实时输出毁伤数量、保存率、模拟精度等核心数据

## 使用说明
### 一、运行准备
1. 将代码复制到C语言编译器中
2. 若使用**Visual Studio**，代码首行`#define _CRT_SECURE_NO_WARNINGS`已关闭安全警告，可直接编译运行
3. 编译无误后，启动程序

### 二、操作流程
1. **输入目标参数**
   - 输入目标总个数（整数）                      e.g. 1
   - 依次输入每个目标的`x`、`y`坐标（实数）       e.g. 10 20
   - 程序自动输出集群目标瞄准点

2. **选择攻击模式**
   - `1`：单方式攻击（四种武器任选其一）
   - `2`：双方式协同攻击（六种组合任选其一）
   - `3`：三方式协同攻击
   - `4`：四方式协同攻击
   - `0`：退出当前目标仿真

3. **配置武器参数**
   根据选择的武器，依次输入：弹药/导弹数量、误差参数、毁伤半径等

输入所选武器的参数
根据你选的武器，程序会依次要求输入：

#### 1）地面火炮
- 炮弹数量（整数）
- 诸元中间误差 Ed、Ef
- 散布误差 Bd、Bf
- 每个目标的等效炸伤半径 Ridp[i]

#### 2）地地导弹
- 导弹数量
- 圆概率偏差 CEP
- 每个目标的等效杀伤半径 Ridd[i]

#### 3）航空火力
- 飞行高度 h、速度 v、俯冲角 a
- 每架投弹数、编队架数、炸点间隔 hx、hy
- 各目标等效炸伤半径 Rihd[i]

#### 4）武装直升机
- 火箭弹数量
- 诸元误差 Ed4、Ef4
- 散布误差 Bd1、bf1
- 各目标等效杀伤半径 Rihj[i]

5. **输入公共参数**
   - 输入每个目标的掩蔽数（权重）
   - 输入模拟精度（控制仿真循环次数，值越小精度越高）

6. **查看仿真结果**
   程序自动完成蒙特卡洛模拟，输出：
   - 被毁伤目标个数
   - 相对毁伤目标数
   - 防护工程保存率
   - 平均毁伤数、置信区间等

7. **重复/退出**
   - 输入`1`：继续仿真新目标
   - 输入`0`：退出整个程序

## 关键参数说明
1. **目标参数**
   - `m`：目标总数量
   - `x[i],y[i]`：第`i`个目标的坐标
   - `x_1,y_1`：集群目标瞄准中心点（程序自动计算）

2. **武器核心参数**
   - 弹药/导弹/火箭数：打击的弹药投放数量
   - 中间误差（Ed/Ef/Bd/Bf）：武器射击偏差参数
   - CEP：地地导弹圆概率偏差
   - 毁伤半径：武器对目标的有效杀伤半径

3. **统计参数**
   - `epsl`：模拟精度，控制仿真循环次数
   - 保存率：未被毁伤的目标比例
   - 相对毁伤数：毁伤目标数/总目标数

---

## 注意事项
1. **输入规范**：所有参数严格按照提示输入，整数输入整数、实数输入小数，否则程序报错
2. **模拟精度**：`epsl`建议输入`0.01~0.1`，值过小会导致模拟时间变长
3. **变量限制**：目标数量最大`100`，模拟次数最大`10000`（宏定义可修改）
4. **协同打击**：多方式攻击需依次输入所有选中武器的参数
5. **随机数**：程序使用系统随机数模拟弹道误差，每次运行结果略有差异（符合真实仿真逻辑）
